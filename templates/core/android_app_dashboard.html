Connection Helper

Copy these examples to test the connection to this endpoint from a device or server.

curl -X GET "{{ app_endpoint }}" \
  -u "{{ selected_app.access_username }}:{{ selected_app.access_password }}" \
  -H "X-Android-App: {{ selected_app.allowed_endpoint|default:'com.example.app' }}" \
  -H "X-Android-Build: {{ selected_app.allowed_build_id|default:'1' }}" \
  -H "X-Android-User-ID: device-user-id-here" \
  -H "X-Android-Device: Pixel 7 Pro" \
  -H "X-Android-OS-Version: 14"
This is a GET request. The endpoint returns the JSON payload with player servers and ads config.
import requests

url = "{{ app_endpoint }}"
headers = {
    "X-Android-App": "{{ selected_app.allowed_endpoint|default:'com.example.app' }}",
    "X-Android-Build": "{{ selected_app.allowed_build_id|default:'1' }}",
    "X-Android-User-ID": "device-user-id-here",
    "X-Android-Device": "Pixel 7 Pro",
    "X-Android-OS-Version": "14",
}

response = requests.get(
    url,
    headers=headers,
    auth=("{{ selected_app.access_username }}", "{{ selected_app.access_password }}"),
)

print(f"Status: {response.status_code}")
print(response.json())
Install with: pip install requests. Replace the placeholder values with actual device info.
