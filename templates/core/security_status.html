How this site is protected

Three independent layers. Each one stops a different kind of automated traffic, so a request has to get past all three to reach the catalogue.

1

Human check (Cloudflare Turnstile)

Every browser answers one quick challenge, once per session. The answer is verified on our server, not in the browser, and a token issued for another website is refused.

2

Edge filtering and rate limiting

Our web server drops known scraper and headless-browser clients before they reach the application, and limits how many requests one address may make per second.

3

Automatic banning

An address that keeps probing — repeated errors or floods — is blocked for an hour automatically. Ordinary browsing never triggers it.

What is not affected

The mobile app and the public API are not asked to solve a challenge, so they keep working exactly as before. Search engines other than Google are not given access, by design. If you are a person using a normal browser, you should never notice any of this beyond the one check.
