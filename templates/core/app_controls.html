App controls

Switch whole content kinds off for the Android app — for everybody, or only for a range of app builds. Rules apply app-wide: never per device, per account or per user. Switching a content kind off also stops new downloads of it on the covered builds, so nobody can queue files that will then refuse to play.

Content rules

{{ rules|length }} configured

A rule applies to the builds between From build and Up to build (leave Up to build empty to keep every newer build working). It travels with the same config the app already downloads, so a switch reaches devices within minutes and needs no app release. A build no rule matches — including a build the app does not report — keeps working exactly as before. Downloads started for a kind that is switched off are refused with the rule's message; files already downloaded are untouched.
