Send mail

Mail and the in-app message can go out together; each recipient gets one row you can retry.

{% csrf_token %}
Used for the “Selected users” audience. An address that never synced still gets the mail; it just cannot get the in-app copy.

How it goes out

Pendingrow written before the attempt — nothing is lost if SMTP is down
Sentthe mail box accepted it for that address
Readthe 1×1 pixel in the HTML body was fetched
Failedkept with the SMTP error; retry as often as you like

Up to 150 addresses per request go out immediately. Anything larger is queued as pending and drained with Retry all pending, so a slow mail box cannot stall the page.

In-app messages show delivered when a device fetches one and read when the user opens it — that tracking is per account, not per mail address.
